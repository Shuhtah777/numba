### Практична 4. Порівняння Numba та NumPy

Параметри експерименту: розмір зображення 1600 × 1200, максимальна кількість ітерацій — 100. Еталонна реалізація написана на Python. Для кожної оптимізованої версії виконано три заміри.

| Реалізація                 | Час, с | Прискорення | Розбіжних пікселів |
| -------------------------- | -----: | ----------: | -----------------: |
| Python, еталон             | 7.6475 |       1.00× |                  0 |
| Numba @njit                | 0.1319 |      57.99× |                  0 |
| Numba @njit(parallel=True) | 0.0273 |     279.73× |                  0 |
| NumPy                      | 3.6886 |       2.12× |                  0 |

Час компіляції Numba вимірювався окремо: 0.6735 с для @njit і 0.5283 с для @njit(parallel=True).

Усі три оптимізовані реалізації дали точний збіг із еталонним зображенням. Найшвидшою виявилася паралельна реалізація Numba.
